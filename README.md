AgroTech, Estudo e Inovação — Agrinho 2026

Objetivo e Justificativa do Projeto:
 O objetivo deste site é explicar ao produtor como funcionam as tecnologias mais utilizadas no campo atualmente, trazendo os valores estimados das mesmas. A tecnologia no campo paranaense transformou a maneira como cultivamos nossos alimentos, e este projeto mostra como Drones Agrícolas, Inteligência Artificial e Sensores de Solo, podem ser eficiêncientes tanto para pequenos quanto para grandes produtores rurais. 

Instruções de Uso:
O site não apresenta dificuldades para uso, portanto, apenas com o rolamento da tela você consegue acessar toda a página. A navegação foi feita de forma simples e objetiva: se o usuário se interessar por alguma das inovações mostradas, é só clicar no botão correspondente para visualizar o valor estimado e acessar um link externo para outros sites que ofereçam o produto real.

 Tecnologias Utilizadas:
* HTML: Utilizada para estruturar toda a página e organizá-la.
* CSS: Foi utilizada para estilizar, definindo fontes, cores e também na função de acessibilidade (Modo Claro e Modo Escuro).
* JavaScript: Auxiliou na criação de interação para a página, dando vida aos botões e deixando o site mais dinâmico.

Detalhes de Organização:
* Organização de Pastas: Todos os recursos visuais do site estão categorizados. As imagens de drones, IA e sensores encontram-se na pasta `/img`.
* Comentários Relevantes: O arquivo `script.js` e `css`possui comentários breves e explicativos para cada função.
* Verificações: O site passou por diversas verificações para que não possua nenhum erro durante o uso.


Originalidade e Identidade Visual:
* Conteúdo Autoral: Todo o roteiro explicativo e a descrição da usabilidade do site foram escritos de forma completamente autoral, enquanto algumas seções do site tiveram uma pesquisa, mas da mesma forma foram escritas de maneira original.
* Customização e Mídias: As imagens utilizadas foram selecionadas em bancos de dados gratuitos (Pixabay).
